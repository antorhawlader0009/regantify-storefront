# Minimog: install into Regantify (not installed yet, kit only)

Template: `templete/others-templetes/General/minimog/minimog` (MINIMOG, general lifestyle store, Shopify style).
Design: white page, forest green `#22632f` (deeper `#184a22`, top bar `#12301a`) as the accent and button fill, sage `#eef0e8` panels, near-black `#111`, Inter everywhere (exists) with bold headings, compact text (11 to 14px), a deep green announcement bar, a white header with 14px links and an underline on the active one, a warm beige hero (`#fbf8f3` to `#e9dccb`) with the picture blended into the right side (multiply + mask), small 8-across category tiles, bordered compact product cards, a sage "sale" banner plus a tall picture card, light neutral panels, a light footer.
Built 2026-11-15 on the Belora kit's code (renamed `Minimog*`, prefix `mg-`, tokens `--mg-*`), recoloured and restyled. Shared-file branches are copied from the `chicwove` ones like the other kits.

## Install
1. `node templete-ready-for-regantify/minimog/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `minimog` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last). No new font needed. No `THEME_CATEGORIES` line is added (a general template shows under Others). Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/minimog`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## What was verified (2026-11-15, repos untouched)
`wire.js` ran on a scratch copy of the storefront/server/client files (junction to node_modules); `tsc --noEmit` there was clean on the first run (the repo has Elevate installed, not the other kits). Client and server were not type-checked (theme-name lists only), nothing was looked at in a browser. Repos stayed at 0 changes.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category: none (Others); add `MINIMOG: [...]` to `THEME_CATEGORIES` if the owner wants a tab.
- Home order: HERO, HIGHLIGHTS (a light neutral strip), CATEGORY_SHORTCUTS (8-across tiles), CAMPAIGNS (the sage sale banner, the second campaign becomes the tall card), FLASH_SALE (the template's countdown circle is StorePal's flash sale section), TOP_SELLING (called "Trending Products", 5 across), CATEGORY_SECTIONS, REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED.
- Header: the shared sticky header (store logo, or the green bag icon with the store name when there is no logo), category strip, search panel; the template's "Collections" dropdown is the store's own menu. No blur on the header (it breaks fixed overlays).
- Left out (no feature, or made-up text): "Trusted by 10,000+ Happy Customers", "4.9 out of 5" and the other sample numbers, the hero's round "UP TO 30% OFF" badge (only drawn when a real value is passed), the countdown, the payment-method badges in the footer (brand rule), the footer currency/country picker, the footer newsletter and sample links, the add-to-cart icon button (a full-width Add to Cart button is always shown instead).
- The footer is light, so the call bar (`FooterCallBar` look `minimog`, generated by `wire.js`) is a deep green gradient band above it with white buttons.

## Needs an eye in the browser
Hero: the picture is multiplied onto the beige (good for white-background product photos, a store's cover photo may look dark or odd), phone layout of the hero, 8 category tiles for stores with few categories, compact 12px card text next to the 14px StorePal parts (checkout, product page), the sale banner with real campaign pictures, product page and cart (Menaura/Belora layout in green).
