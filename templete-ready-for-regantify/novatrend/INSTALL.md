# Novatrend: install into Regantify (not installed yet, kit only)

Template: `templete/others-templetes/General/novatrend/novatrend` (NOVATREND, general store, trendy).
Design: white page and header under a **black** announcement bar, vivid orange `#ff4b0f` (deeper `#e63e05`, pale `#fff1eb`) as the accent and button fill, near-black `#0b0b0b` hero and footer, light grey `#f6f6f6` rounded product cards with a white square photo and a black pill Add to Cart (orange on hover), Inter everywhere (exists) with extra-bold headings, a full-height black hero with the picture on the right under a black fade and an orange glow, six rounded category cards, two rounded promo tiles (orange gradient and black).
Built 2026-11-15 on the Furnilux kit's code (renamed `Novatrend*`, prefix `nt-`, tokens `--nt-*`), because Furnilux already has a white header, a dark footer and a green accent; recoloured and restyled. Shared-file branches are copied from the `chicwove` ones like the other kits.

## Install
1. `node templete-ready-for-regantify/novatrend/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `novatrend` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last). No new font needed. No `THEME_CATEGORIES` line is added (a general template shows under Others). Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/novatrend`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## What was verified (2026-11-15, repos untouched)
`wire.js` ran on a scratch copy of the storefront/server/client files (junction to node_modules); `tsc --noEmit` there was clean on the first run (the repo has Elevate installed, not the other kits). Client and server were not type-checked (theme-name lists only), nothing was looked at in a browser. Repos stayed at 0 changes.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category: none (Others); add a line to `THEME_CATEGORIES` if the owner wants a tab.
- Home order: HERO, HIGHLIGHTS (a grey panel), CATEGORY_SHORTCUTS (six cards), TOP_SELLING ("New Arrivals", 5 across), FLASH_SALE (the template's countdown tile is StorePal's flash sale section), CATEGORY_SECTIONS, CAMPAIGNS (the orange and black tiles), REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED. The template's second row "Best Sellers" is not a separate section here (the product grid shows once).
- Header: the shared sticky header, with the black Site Banner bar above it (no banner text, no bar). The template's "Categories" dropdown is the store's own category strip.
- Left out (no feature, or made-up text): the sample announcement texts ("Free Worldwide Shipping Over $50", "Summer Sale Up To 70% Off"), the round cart icon button on cards (a full-width pill Add to Cart is always shown), the hero's three sample slides and the countdown (the store's own slides and flash sale show), the footer's blog posts, payment brand names and sample contact lines, the trust strip's sample promises (the store's Highlights show).
- The footer is black and re-points colour variables, so the call bar (`FooterCallBar` look `novatrend`, generated by `wire.js`) uses fixed colours: an orange band with white buttons.
