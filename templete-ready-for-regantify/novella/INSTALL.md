# Novella: install into Regantify (not installed yet, kit only)

Template: `templete/others-templetes/General/novella-store/novella-store` (NOVELLA, general marketplace).
Design: warm cream page and header `#faf8f5`, terracotta `#c0714e` (deeper `#a85d3c`) as the accent, sand `#f4efe9` panels, near-black `#111` buttons, near-black hero `#0a0a0a` and footer `#141414`, white thin-bordered product cards with a 1:0.92 photo and an outline Add to Cart (fills black on hover), **Manrope** everywhere (new, added by `fonts-patch.js`) with extra-bold headings; a two-row header (logo, wide search bar with a black button, icons; then a menu row), a full-screen dark hero with the picture across and terracotta words, round category pictures (8 across), three promo tiles (pale terracotta, sand, black), a sand feature strip.
Built 2026-11-15 on the Novatrend kit's code (renamed `Novella*`, prefix `nv-`, tokens `--nv-*`), restyled; shared-file branches are copied from the `chicwove` ones like the other kits.

## Install
1. `node templete-ready-for-regantify/novella/wire.js` from the workspace root (theme, demo route, CSS block, Manrope in `lib/fonts.ts`, enum + migration, `novella` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last; `Trending Products` as the top-selling title). No `THEME_CATEGORIES` line (a general template shows under Others). Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/novella`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category: none (Others).
- Home order: HERO, CATEGORY_SHORTCUTS (round pictures), CAMPAIGNS (promo tiles), TOP_SELLING, FLASH_SALE, CATEGORY_SECTIONS, HIGHLIGHTS (the sand strip), REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED. The template's second row "Recommended for You" is not a separate section here (one product grid).
- Header: the cream announcement bar is StorePal's Site Banner (no banner text, no bar); the template's top-bar links (Track Order, Help Center, Sell on Novella) are left out. The wide search bar opens the shared search panel; below 1024 px a search icon is shown instead. The menu row shows the store's own menu, else All products, four categories and Sale; the template's "Categories" dropdown is not drawn (the store's own categories are in the menu).
- Left out (no feature, or made-up text): the sample reviews, the newsletter block (no email feature), app-store badges, the "Sell on Novella" link, the template's demo toasts, sample announcement and promise texts. The cards have no star line-up change: ratings show as in the other kits.
- The footer is dark and re-points colour variables, so the call bar (generated by `wire.js`) uses fixed colours: a terracotta band with white buttons.
