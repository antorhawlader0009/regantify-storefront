# Mallon: install into Regantify (not installed yet, kit only)

Template: `templete/others-templetes/Beauty and Health/mallon-store/mallon-store` (MALLON, healthcare store, marketplace style).
Design: white page, coral `#d9534f` (accent, button fill, "Search", tags), teal `#1fb89a` (prices, a top announcement bar, feature icons), sand `#f5f5ef` (footer and bands), text `#222`, Poppins everywhere (`--font-poppins`, exists), small compact text (12 to 13px), a **two-row header** (logo, wide search bar with a coral Search block, icons; second row: a coral "All Categories" block and the menu), a big blue gradient hero banner with the picture fading in on the right, gradient promo tiles (blue, teal, lilac), flat product cards, a sand footer.
Built 2026-11-15 on the Belora kit's code (renamed `Mallon*`, prefix `ml-`, tokens `--ml-*`), recoloured and restyled. Shared-file branches are copied from the `chicwove` ones like the other kits.

## Install
1. `node templete-ready-for-regantify/mallon/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `mallon` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last, Templates category `Beauty & Health`). No new font needed. Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/mallon`, phone width, footer, the two header rows.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category on the Templates page: `Beauty & Health`.
- Home order: HERO, HIGHLIGHTS (a plain bordered strip), CATEGORY_SHORTCUTS (small round sand circles), CAMPAIGNS (the gradient tiles), FLASH_SALE (the template's "Today's Hot Deals" is StorePal's own flash sale section), TOP_SELLING (called "Best Sellers", 5 across), CATEGORY_SECTIONS, REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED.
- Header: the wide search bar opens the shared search panel (the template has an inline input); "All Categories" links to the product list (the template opens a dropdown of categories); on a phone the burger menu and the search icon are used. The announcement bar (the store's Site Banner) is teal, no banner text means no bar.
- Left out (no feature, or made-up text): the template's "Aqium Hand Sanitiser" and other sample banner texts, the "Best Selling Products" thumbnail row (the product grid covers it), the countdown timers inside deal cards (StorePal's flash sale has its own timer), the bottom two banners, the footer newsletter box and the sample footer links (the store's own footer columns show), the hover cart/heart round buttons (Add to Cart is always visible).
- Footer is light sand, so no colour re-pointing for it; the call bar (`FooterCallBar` look `mallon`, generated by `wire.js`) is a teal gradient band with white buttons.
