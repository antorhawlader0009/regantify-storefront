# Belora: install into Regantify (not installed yet, kit only)

Template: `templete/others-templetes/Beauty and Health/belora-skincare/belora-skincare` (BELORA, skincare and beauty).
Design: white page, violet `#6b3fa0` (accent, button fill, active nav, prices of focus, section lines), pale violet `#f5f0fa` panels, soft violet `#e8dcf4` lines, ink `#1e1b26`, Cormorant Garamond headings (`--font-cormorant`) over Inter, a violet announcement bar, a lavender hero (`#f1e9f9` to `#e1d3f2`) with a rounded picture on the right, round category icons, a pale violet feature panel under the hero, a split "self care" banner, a **white** footer with violet headings.
Built 2026-11-15 on the Menaura kit's code (renamed `Belora*`, prefix `be-`, tokens `--be-*`), recoloured and restyled. Shared-file branches are copied from the `chicwove` ones like the other kits.

## Install
1. `node templete-ready-for-regantify/belora/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `belora` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last). No new font needed (Cormorant Garamond and Inter exist). Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/belora`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## Decisions and notes
- Plan: last in `THEME_ORDER` (before the `...Object.values(StoreTheme)` spread).
- Category on the Templates page: `Beauty & Health` (`wire.js` adds `BELORA: ['Beauty & Health']`).
- Home order: HERO, HIGHLIGHTS (the pale panel sits directly under the hero, so keep it second), CATEGORY_SHORTCUTS, FLASH_SALE, CAMPAIGNS (the split band), TOP_SELLING (called "Best Sellers"), CATEGORY_SECTIONS, REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED. The panel has a `-mt-8` overlap with the hero; if a store moves it elsewhere it just overlaps the section above.
- **The footer is light** (the other kits have dark ones), so this kit's CSS has no footer colour re-pointing, `BeloraFooter` uses ink/violet text on white, and the call bar (`FooterCallBar` look `belora`, generated by `wire.js`) is a violet gradient band with white buttons above it.
- Left out (no feature, or made-up text): the "Story" band with its numbers (100% / 50+ / 10K+ / 25+), the template's four sample promises (the store's own Highlights show instead), the footer newsletter box, "FREE SHIPPING OVER $75 / 10% OFF" (the store's own Site Banner shows in the violet bar; no banner text, no bar), the ingredients/batch/expiry details and the template's account drawer (StorePal has its own product page and account).
- Round category icons: the template draws line icons; here a store's category photo fills the circle (first letter if none).

## Needs an eye in the browser
Hero spacing and the rounded picture (the picture box is 680:440, a store's cover photo may crop oddly), the feature panel overlap, the 6 round categories on phones (sideways scroll), card look (violet hairline border, square pale photo, outline violet Add to Cart), the product page and cart (Menaura/Chicwove layout in violet), header search (shared search panel; the template has an inline box with a violet button), footer columns (the shared columns, not the template's five).
