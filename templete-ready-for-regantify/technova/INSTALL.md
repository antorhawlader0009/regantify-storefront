## Install
1. `node templete-ready-for-regantify/technova/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `technova` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last, category `Technology & Gadgets` in `Themes.tsx`). No new font. Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/technova`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category: Technology & Gadgets (TechZone is in the same tab).
- Home order: HERO, CATEGORY_SHORTCUTS, TOP_SELLING (Trending), CAMPAIGNS (the flash and new-arrival tiles from a store's own campaigns), FLASH_SALE, CATEGORY_SECTIONS, HIGHLIGHTS (the four-item benefits row), REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED.
- **Blue fills carry white text** and `--color-accent` is the electric blue, so shared buttons (checkout, cart) are blue too. The hero's headline word is a blue-to-violet gradient text; the template's hand-written "Technology for a Brighter You" caption is not built.
- The navy header is one row in this kit (logo, menu, search, icons); the template's two-row header (search under the logo, a second gradient menu row) is only drawn that way in the demo. The store's own menu fills the row.
- Cards: soft-blue Add to Cart (the template's), the tagline under the name only in the demo (a real product has no tagline field).
- Left out: the currency selector and Help / Track Order links in the top bar, the newsletter band (StorePal's footer has none), the login page (StorePal's own sign-in dialog), the product filters on /shop (StorePal's own list), the app-store badges.
- The footer is white, so the call bar (generated by `wire.js`) is a soft blue band with a blue button.
