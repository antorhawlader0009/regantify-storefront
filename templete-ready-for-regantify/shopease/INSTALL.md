## Install
1. `node templete-ready-for-regantify/shopease/wire.js` from the workspace root (theme, demo route, CSS block, enum + migration, `shopease` branch next to every `chicwove` one in 29 shared files, THEME_ORDER entry last, `New Arrivals` as the top-selling title). No new font. No `THEME_CATEGORIES` line (a general template shows under Others). Rerun-safe.
2. Server: `prisma generate` (stop the API first), `migrate deploy` locally and on production through the tunnel, `tsc --noEmit`.
3. `tsc --noEmit` in storefront, `tsc -b` in client.
4. Browser check on `shopnet` only: home, list, product, cart, wishlist, checkout, account, Bangla switch, `/template-demo/shopease`, phone width, footer.
5. CLAUDE.md line, commit as Antor, push only when the owner says.

## Decisions and notes
- Plan: last in `THEME_ORDER`. Category: none (Others).
- Home order: HERO, CATEGORY_SHORTCUTS (five cards), FLASH_SALE (the template's Deal of the Day with its countdown is StorePal's flash sale section), CAMPAIGNS (the peach deal panel from a store's own campaign), TOP_SELLING ("New Arrivals", 4 across), CATEGORY_SECTIONS, HIGHLIGHTS (the peach strip), REVIEWS, MAGAZINE, FAQ, SOCIAL_FEED.
- Header: the centred menu between the logo and the icons is kept; the template's compact search box is the shared search icon + panel. The forest green top bar is StorePal's Site Banner (no banner text, no bar), so the template's "FREE SHIPPING / EXTRA 10% OFF" lines only show if the store writes them.
- Left out (no feature, or made-up text): the newsletter block (no email feature), the Deal of the Day's fixed "23 left" bar and fake countdown (the store's own flash sale shows), the "View in Browser" link, the template's bag logo mark (a store's own logo, else an orange letter tile), the wishlist/cart toasts.
- The footer is light, so the call bar (generated by `wire.js`) is a forest green band with white buttons.
